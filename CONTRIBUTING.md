# Contributing to Lead Scoring Model

Thank you for your interest in contributing to this lead scoring project!

## How to Contribute

### Reporting Issues
- Check existing issues first
- Provide detailed descriptions with data samples
- Specify the impact on model performance

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Install dependencies: `pip install -r requirements.txt`
4. Make your improvements
5. Test model performance before submitting
6. Push and create a Pull Request

## Code Guidelines

- Follow PEP 8 conventions
- Document model changes
- Include performance metrics
- Add comments for complex logic

## Areas for Contribution

- Improving lead scoring accuracy
- Adding new features
- Better lead segmentation
- Enhanced visualizations
- Performance optimization
- Documentation improvements

## Pull Request Process

1. Ensure model validation is complete
2. Update README with any new insights
3. Provide performance comparison

Thank you for contributing! 🙏
